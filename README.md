# HashAndHammer-web-project

## Project 2 - HTML Foundation Page

This project is a basic HTML website created for my ICT280 course. The theme of my website focuses on my interests and learning web development.

### What I Learned
- How to structure a complete HTML document
- How to link multiple pages together
- How to organize files in a project
- How to validate HTML using the W3C validator

### Challenges
- Fixing validation errors in my HTML code
- Understanding proper file structure and linking between pages
- Making sure everything worked correctly on GitHub Pages

## Project 3 - Adding CSS and Images

In this project, I expanded my website by adding an 
external CSS file to improve the overall design and 
layout.

### What I Learned

I learned how to separate structure (HTML) 
from styling (CSS), which made the site more 
organized and easier to manage. I also added locally 
stored images and practiced using relative file 
paths to correctly display them across different 
pages. Overall, this project helped me gain 
confidence in linking files together and debugging 
real-world issues in web development.

### Challenges

One of the main challenges I faced was 
troubleshooting why images were not appearing on 
GitHub Pages, which helped me better understand file 
structure, pathing, and how GitHub handles deployed 
websites.
